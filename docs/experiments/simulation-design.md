# 初步模拟设计（待规格化）

## 目的

先研究“结构—环境相互作用是否形成可重复的新系统属性”，而不是直接模拟或宣称模拟意识。

## 最小模型候选

- 系统：由多个相互作用单元构成的网络或格点系统。
- 状态：每个单元具有可明确定义的离散/连续状态。
- 环境：外部驱动、资源/能量输入、噪声、边界条件。
- 相互作用：局部耦合规则，允许系统状态影响环境反馈；同时允许环境反过来影响单元。
- 候选结构指标：网络连通性、模块化、稳定性、相关长度、状态转移结构。
- 候选属性指标：持续性、适应性、记忆、信息传递或复制动力学等；必须逐项定义，不能把它们直接叫作意识。

## 对照组

1. 无环境反馈；
2. 无内部相互作用；
3. 随机网络/随机驱动空模型；
4. 参数匹配但缺少候选关键条件的模型；
5. 已知自组织机制模型作为竞争解释。

## 分析

- 多随机种子重复运行；
- 参数扫描与敏感性分析；
- 结构与属性指标分别测量；
- 预先定义效应量与失败标准；
- 报告阴性结果和模型失败。

## 当前限制

该设计只是研究模板。基础结构 U、“本属性环境”与属性 P 尚未得到足够定义，故当前不应宣称已有可执行的最终模拟。下一步先完成概念操作化与文献证据地图。
