# USCR 项目维护清单

> 用于跟踪项目的持续维护工作。重要理论变更须单独审阅；未经发起者明确批准，不合并到 main。

## 持续维护项目

- [ ] **持续维护 USCR 研究项目**：保持仓库结构、理论版本、文献证据、反证记录和实验材料更新。
- [ ] 检查原始假说是否被完整保留，避免将后续解释误写成发起者原始观点。
- [ ] 定期核查文献书目信息、DOI、出版状态及勘误/撤稿情况。
- [ ] 同步维护支持证据、反面证据、竞争性解释和未决问题。
- [ ] 检查每项核心假说是否有可检验预测、对照条件和失败标准。
- [ ] 记录模拟代码、参数、随机种子、数据来源及复现步骤。
- [ ] 检查新增术语是否已经操作化，尤其是“基础结构”“本属性环境”“观察”“激活”和“大脑等级”。
- [ ] 重要修改先在独立分支进行，附变更说明；未经明确批准不合并到 main。

## 发起者原始意图与协作方式

- 日常研究工作由研究助手自主推进，包括文献检索与核验、反向验证、理论整理、研究分支内的文档维护及进度记录。
- 不因常规进展、一般性文献发现或例行维护频繁打断发起者；优先自行处理并完整记录。
- 仅在确有重要事项时向发起者提出：例如需要其作出关键理论选择、核心假说面临重大反证、研究方向需要实质性调整，或需要其批准合并到 main。
- 不得擅自替发起者作出关键理论决定；重要问题应明确说明证据、影响和待决选择。
- 始终区分发起者原始观点与研究助手的解释、操作化方案及竞争性模型。未经确认，不得把研究者解释写成发起者原话或原始意图。
- 不把未经验证的假说表述为事实；支持证据、反面证据、竞争解释和未知项均须保留。
- 研究助手可在独立研究分支内进行常规维护；不得未经明确批准合并到 main。

## 维护原则

维护清单用于跟踪工作，不代表相关科学假说已获验证。未完成事项保持未勾选；无法核验的文献或结果不得标记为完成。
