# USCR 概念操作化备忘录（v0.2）

## 目的

把发起者提出的概念转成可研究变量，同时避免把研究者的解释冒充为发起者原意。本文不修改原始假说；它提出的是待讨论的研究操作化方案。

## 一、必须区分的三个层次

1. **存在层**：某系统是否存在、由什么物理/生物/人工载体构成。
2. **功能层**：系统是否活动、调节自身、整合信息、学习、复制/延续或与环境交换信息。
3. **体验层**：系统是否具有主观体验（现象意识）。

功能层的阳性结果不自动推出体验层阳性。尤其是刺激响应、复杂行为、信息处理、学习或自我复制，都不能单独作为意识的充分证据。

## 二、发起者提出的候选条件

发起者提出“可以活动、可以繁殖、可以观察”为意识定义的必要条件之一部分，并明确表示还需要其他条件。另提出系统自身应具备交流能力，交流不依赖人为外接接口；但交流不是唯一判据。

以下是研究者提出的暂定测量方向，不是已经达成的完整意识定义。

### C1 活动（activity）

候选指标：
- 在预先规定的时间窗内，系统状态发生可重复的内部变化；
- 区分内部自发动力学与单纯外部驱动的被动变化；
- 记录能量/物质交换、状态转移、稳定性与扰动后的恢复。

待澄清：活动是否必须自发？仅有外部刺激下的变化是否满足？时间尺度如何设定？

### C2 繁殖/延续（reproduction / persistence）

发起者已说明此条件指基础系统层面的产生、复制或延续，不要求每一个意识主体都能生殖；并允许非生物形式的结构/机制复制。

操作化时至少分开：
- 个体复制：产生一个结构上可比的后继系统；
- 系统延续：同一系统跨时间维持组织与功能；
- 复制保真度：后继系统保留哪些结构/功能特征；
- 复制与体验主体的关系：不能预设每个副本都是同一个主体。

待澄清：延续是否可替代复制？复制的最低相似度标准是什么？仅由外部制造者复制是否符合原意？

### C3 可观察——已由发起者澄清为系统自身感知/检测外界

**发起者确认选择 A：系统自身能够感知或检测外界。**

因此，本项目在记录发起者原意时，将“可以观察”解释为系统自身具有对外部环境进行感知/检测的能力；不解释为外部人类观察者能够测量系统，也不要求系统必须向人类表达其内部状态。

研究者提出的候选操作化指标（仍待验证和细化）：
- **环境刺激检测**：系统对某类外部变量变化产生可重复、可区分的响应；
- **刺激区分能力**：对不同刺激类别或强度呈现可区分的状态变化，而非对所有扰动作完全相同的被动响应；
- **内部状态登记**：外部变化在系统内部留下可检测的状态改变，且该改变与刺激类别/历史有关；
- **功能性耦合**：检测结果能够影响系统后续状态调节或行为。

必须注意：
- 单纯受力、受热或发生物理变化，不自动等于系统具有感知能力；
- 感知/检测能力不自动证明主观体验；
- 外部研究者能否测量该系统，是研究方法问题，不是发起者在此处所说的“可以观察”；
- 系统是否能把内部状态表达给人类，是交流/报告问题，不是本项条件本身；
- 人类无法解码系统的信号，不构成该系统缺乏感知能力的证据。

### C4 内生交流（intrinsic communication）

候选指标：
- 系统内部不同部分之间存在可检测的信息传递；
- 系统与外界之间存在由系统自身组织实现的信息交换；
- 不依赖研究者临时添加的专用接口或翻译设备，才能产生该能力。

需区分“系统内部信号传递”“系统与环境的信息交换”及“向外部观察者表达主观体验”。后者不是前两者的必然结果。

待澄清：发起者所说的“交流”是否包括系统内部部件间通信？是否必须有系统边界外的对象参与？

## 三、建议的最小测量向量

对候选系统记录向量，而不是直接给出意识二元标签：

X = (A, R, O_s, O_m, K, I, H, B)

- A：活动/内部状态变化
- R：复制或延续能力
- O_s：系统自身感知/检测环境（发起者已确认“可以观察”对应此项）
- O_m：外部可测量性（研究方法变量，不是“可以观察”的原意）
- K：内生交流
- I：跨部分信息整合
- H：学习/历史依赖
- B：行为灵活性与目标调节

这些指标是功能描述。主观体验仍需独立的理论桥接原则和可反驳预测。

## 四、最小研究设计原则

- 对照系统必须尽可能匹配能量供给、规模、环境、组织复杂度和测量条件。
- 每个变量都要有正负对照、重复测量和预先定义的排除标准。
- 不能以“行为复杂”直接推断意识；也不能以“人类无法解码其信号”推断它没有交流或意识。
- 跨物种比较优先采用非侵入性、低干扰方法；不以破坏性切除作为首选实验。
- 将“没有观察到”与“证明不存在”严格区分，并报告检测灵敏度。
- 新增辅助条件必须在下一轮实验前登记，不得在结果不符后临时添加。

## 五、对原始理论的保护

原始概念“本属性环境”继续保留原词，暂不替换成“生态位”“意识场”“信息场”等现成概念。研究者可以提出候选解释，但必须另列并标明来源。基础结构不称为“原始意识”或“潜在意识”；是否存在意识属性，只能在属性被独立刻画后再判断。

## 六、待发起者确认的关键问题

1. “活动”是否要求系统有内部自发活动，还是外部刺激下发生变化也算？
2. “繁殖/延续”中，系统持续存在但不复制，是否满足该条件？
3. “交流”是否包括系统内部不同组成部分之间的信息传递？
4. “大脑等级”应按哪些可量化功能维度定义？不能使用脑体积作为替代指标。
5. 对“感知/检测外界”，最低要求是仅能区分外界变化，还是还必须把检测结果用于内部调节？这将决定后续操作化边界。
