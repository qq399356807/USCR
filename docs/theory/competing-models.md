# 竞争性解释与对照框架

研究必须同时评估下列模型，不以 USCR 假说作为默认解释。

| 模型 | 核心主张 | 对 USCR 的挑战/可区分预测 |
|---|---|---|
| 神经相关/神经生成模型 | 人类意识与特定神经动力学高度相关，意识可能由脑内过程实现 | 麻醉、睡眠、脑损伤等对意识报告的系统影响，是否与非脑基础解释相容？ |
| 全局神经工作空间理论（GNWT） | 信息经由广泛广播进入全局可用状态，与意识访问相关 | 是否需要可识别的广播/点火动力学？非神经系统是否存在功能同构机制？ |
| 整合信息理论（IIT） | 意识与系统内在因果结构/整合程度相关 | 其形式化指标能否可靠测量，是否产生可区分预测？ |
| 高阶表征理论 | 意识状态依赖系统对自身心理状态的某种高阶表征 | 无法显示高阶表征的系统是否仍可能有意识？ |
| 循环处理理论 | 特定形式的循环/递归处理与意识相关 | 递归动力学是否足够，是否必要？ |
| 预测处理/主动推断 | 系统通过预测、误差最小化及行动调节与环境耦合 | USCR 所说的激活是否只是已知预测—反馈机制？ |
| 复杂系统/自组织 | 局部相互作用可形成宏观秩序和新性质 | 新属性是否仅为一般自组织结果，无需意识相关解释？ |
| 非平衡热力学 | 能量流、耗散和远离平衡状态可维持复杂结构 | 环境驱动的结构形成是否可由热力学充分解释？ |
| 生命系统/自创生 | 自我维持、边界生成、代谢和组织闭合构成生命特征 | USCR 的“繁殖/延续”与生命定义有何差异？ |
| 泛心论/宇宙意识论 | 意识或其基本成分可能具有普遍/基础地位 | USCR 明确不预设基础结构是意识；需避免概念偷换 |
| 纯功能主义/计算主义 | 特定功能组织或计算结构可实现意识 | 物理载体是否重要？系统复制/模拟是否保持相关属性？ |

## 竞争模型比较要求

每个模型需记录：核心定义、必要条件、可测量预测、支持证据、反例、争议、对 USCR 的解释力和剩余问题。不得仅凭术语相似就宣称两个理论等价。
