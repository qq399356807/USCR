# 术语与操作化定义（工作稿）

本文件区分发起者用语、研究工作定义与尚未解决的问题。定义在获得证据前均为暂定。

| 术语 | 当前工作描述 | 操作化任务 |
|---|---|---|
| 基础结构 U | 假说中普遍存在、可与环境相互作用的基础性结构/机制；不称为意识 | 指定物理载体、尺度、状态变量、测量方式 |
| 外部环境 E | 与基础结构发生相互作用的条件集合 | 列出可操控变量、边界条件与时间尺度 |
| 相互作用 I | U 与 E 双向影响的过程 | 建立因果干预、响应函数与对照条件 |
| 本属性环境 | 发起者提出的暂定术语，可能由结构—环境相互作用形成 | 发起者进一步澄清其边界、组成和可测量性质 |
| 激活 | 某些结构—环境组合使系统进入不同状态或表现出新能力的候选机制 | 与普通响应、阈值效应、相变及反馈机制区分 |
| 结构 S | 相互作用后形成或改变的系统组织状态 | 结构指标、稳定性、可重复性和形成条件 |
| 新属性 P | 结构出现后可观测的系统性质；不预设为意识 | 预先指定属性指标与检测灵敏度 |
| 意识 | 需要依据明示判据作出的分类，不预先赋予 U 或 P | 建立判据、证据等级、反例及不确定性规则 |
| 活动 | 发起者提出的意识候选条件之一 | 区分热运动、反应、主动调节、持续自主活动 |
| 繁殖/延续 | 基础系统可复制、延续或再生成同类系统；不要求单个主体能繁殖 | 定义复制保真度、谱系连续性、能量/物质依赖 |
| 观察（发起者原意） | 系统自身能够感知或检测外部环境；不是外部人类观察者测量，也不要求向人类表达 | 区分刺激检测、刺激区分、内部状态登记及检测结果对调节的影响 |
| 外部可测量性 | 研究者能否从外部测量系统状态；与发起者所说“观察”不是同一概念 | 说明仪器、检测阈值、测量误差和不可观测区间 |
| 交流 | 系统自身具备的信息交换能力，是重要但非唯一线索 | 区分内部耦合、系统间信号与人为接口 |

## 意识判据的暂定纪律

发起者提出的“活动、繁殖、观察”是必要考虑项，但尚不足以形成完整判据。研究团队不得擅自将它们解释为已被证明的必要或充分条件。

其中，“可以观察”已由发起者明确为**系统自身感知/检测外界的能力**。这一能力需要和普通物理刺激响应区分，但不能未经论证就要求系统必须能向人类报告内部状态。

可将意识相关证据分层记录，而不急于二元判定：
1. 可重复的环境响应；
2. 对不同环境刺激的区分及内部状态登记；
3. 多变量信息整合与灵活调节；
4. 跨情境学习、记忆或目标导向行为；
5. 系统自身产生的交流/信号；
6. 与主观体验相关的独立证据（具体指标需谨慎论证）。

这些层级不是通用的意识定义，也不意味着高层级行为自动证明主观体验。
