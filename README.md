# USCR — Universal Structure & Consciousness Research

> 宇宙基础结构与意识属性形成研究

USCR 是一个探索性、可证伪的跨学科研究项目，研究基础结构、环境及其相互作用是否能够形成新的系统结构与属性，并进一步检验其中某些属性是否符合明确的意识判据。

**项目立场：研究假说，而非宣称结论。** 本项目不预设宇宙基础结构本身就是意识，也不把复杂性、信息处理、刺激响应或自组织直接等同于意识。

## 当前阶段

- 项目版本：v0.1（假说登记与研究框架初始化）
- 仓库状态：初始基线
- 当前重点：概念操作化、竞争性解释、反证标准与文献核验
- 研究原则：支持证据与反面证据并列记录；不自动合并重要修改

## 核心研究问题

1. 是否存在可跨不同物理系统描述的普遍基础结构？
2. 基础结构与外部环境如何相互作用，是否会形成特定结构或“本属性环境”？
3. 特定结构—环境组合是否会使新的系统属性出现？
4. 若某种属性出现，哪些可检验判据能够判断它是否属于意识？
5. 大脑是否为意识的必要条件，还是意识与现实交互的一种实现工具？

## 非预设意识原则

“意识”是研究者使用的概念分类。基础结构、环境、相互作用及其产生的结构，在得到充分定义和证据前均使用中性术语。只有在观察到某种属性后，才根据事先明确的判据讨论它是否符合意识定义。

## 研究纪律

- 将用户提出的原始假说与后续科学解释、模型修订分开存档。
- 同时检索支持、反对及竞争性理论，不进行确认偏误式文献搜集。
- 区分行为复杂性、信息处理、环境响应、生命活动与主观体验。
- 每项假说必须给出可观测预测、反例条件和失败标准。
- 不以“尚不能识别”作为免疫反证的理由。
- 不因实验失败而临时增加未预先说明的隐藏条件。
- 对动物研究优先采用非侵入式、伦理审查合规的方法。
- 所有文献的作者、题名、期刊、年份及 DOI 均需核验后再纳入正式书目。

## 版本与治理

重要理论修改应先形成独立分支和变更说明，经审阅后再决定是否合并。原始假说不得被后续修订覆盖；证据支持、反面证据与未决问题分别维护。
